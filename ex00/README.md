# Personal Portfolio - Project 04 (ex00)

## Description
An authentic, fully responsive personal portfolio website built completely from scratch without external templates, UI frameworks, or libraries (such as Bootstrap or Tailwind), fulfilling the strict requirements of 42 Core curriculum.

## Features
- **Semantic HTML5 & Modern CSS3:** Clean layout structured with Flexbox and CSS Grid.
- **Dynamic Theme Switcher:** Interactive JavaScript theme toggler supporting smooth dark/light mode switching and persisting user choice.
- **Responsive Design:** Media queries ensuring seamless adaptation across mobile devices, tablets, and desktops.
- **Professional Sections:** Header/Navbar, About Me, Skills Matrix, Project Showcase (incorporating backend & systems projects), Hobbies, and Interactive Contact Form.

## Technologies Used
- HTML5, CSS3, JavaScript (ES6+)
- Git for version control

## Instructions to Run
1. Clone the repository to your local machine.
2. Open the `ex00/index.html` file in any modern web browser or run a local server (e.g., Python's `http.server`).
